# Southwest Power Pool (SPP)

> Nonprofit Regional Transmission Organization regulated by FERC, headquartered in Little Rock, Arkansas. SPP operates the Integrated Marketplace day-ahead and real-time markets, the Western Energy Imbalance Service (WEIS) market, Western Reliability Coordination services, and is building the Markets+ day-ahead market for the West. It is a wholesale operator with no retail customers. Its API posture is a clean split: market and grid data is genuinely open and anonymous, while everything a market participant transacts against is member-gated behind an x.509 certificate and an SPP UAA role.

Generated by API Evangelist on 2026-07-27 from https://github.com/api-evangelist/spp — SPP publishes no llms.txt of its own (probed: www.spp.org/llms.txt 404, portal.spp.org/llms.txt returns the SPA shell).

## Open APIs (no credential required — verified anonymously 2026-07-27)

- [SPP Public Data FTP](https://spp.org/documents/28853/spp%20public%20data%20access%2020230707.pdf): ftp://pubftp.spp.org — the programmatic access path SPP formally supports. Anonymous listing returned FTP 226.
- [SPP Portal file browser](https://portal.spp.org/pages/rtbm-lmp-by-location): GET https://portal.spp.org/file-browser-api/download/{dataset}?path={file} returns CSV for real-time and day-ahead LMP, market clearing prices, operating reserves, hourly load, generation mix, VER curtailments, outage capacity and the WEIS equivalents. No listing endpoint exists; paths are constructed by convention.
- [SPP Portal chart API](https://portal.spp.org/pages/generation-mix-historical): GET https://portal.spp.org/chart-api/gen-mix/asChart and /load-forecast/asChart return JSON series; /gen-mix-365/asFile returns a rolling 365-day CSV.
- [SPP price contour map](https://pricecontourmap.spp.org/arcgis/rest/services): Esri ArcGIS Server 11.5 REST directory (?f=json) serving DA_LMP, RTBM_LMP, DELTA_LMP, States and Transmission MapServer services.

## Member-gated APIs (x.509 certificate + SPP UAA role; no public base URL)

- [SPP LEP/TROLIE Ratings API](https://www.spp.org/documents/72496/spp%20lep%20api%20data%20exchange%20guide.pdf): SPP's FERC Order 881 ambient-adjusted ratings exchange, implemented against the LF Energy TROLIE specification. Data Exchange Guide v1.0, 2024-11-08.
- [SPP Integrated Marketplace web services](https://www.spp.org/documents/73131/spp%20system%20interfaces%20stakeholder%20reference%20guide%2020250129.pdf): SOAP market and notification services, Settlement Management System API, WEIS Markets Web Service. WSDL/XSD live in the member-only Change User Forum. Markets+ is stated to move to RESTful APIs at its targeted 2027 go-live.

## Notes for agents

- No signup, key or token is needed for anything under "Open APIs". Send no Authorization header.
- A 200 with content-type text/html and ~609 bytes from portal.spp.org is the React shell, not data.
- SPP publishes no OpenAPI, Postman collection, SDK, CLI, MCP server, webhook catalog or AsyncAPI of its own.
- Do not fabricate a base URL for the LEP/TROLIE API — SPP's own guide uses the placeholder https://<baseURL>/.
